**Responsável:** (coloque o nome)

O **HTTP (HyperText Transfer Protocol)** é o protocolo responsável pela comunicação entre o navegador e o servidor na internet. Ele define como as informações são enviadas e recebidas.

A diferença entre **HTTP e HTTPS** é que:

- **HTTP** não possui segurança (dados não são criptografados)  
- **HTTPS** possui segurança, utilizando criptografia SSL/TLS  

O **HTTPS é importante** porque protege os dados do usuário, evitando que informações como senhas e dados pessoais sejam interceptadas por terceiros.

### Papel do navegador

O navegador é o programa usado para acessar sites. Ele:

- envia requisições para o servidor  
- interpreta HTML, CSS e JavaScript  
- exibe o conteúdo para o usuário  

### Papel do servidor web

O servidor web é responsável por:

- armazenar os arquivos do site  
- processar requisições  
- enviar as páginas ao navegador  

### Comunicação entre eles

Exemplo de funcionamento:

1. usuário digita um endereço no navegador  
2. o navegador envia uma requisição HTTP/HTTPS  
3. o servidor responde com os arquivos do site  
4. o navegador exibe a página
