O QUE É CSS?

Estilizando páginas web com estilo 😎

📌 Definição

O CSS (Cascading Style Sheets) é uma linguagem usada para estilizar páginas web, definindo cores, fontes, tamanhos e layout.

🎯 Seletores

Escolhem quais elementos serão estilizados.

p { color: red; } .titulo { color: blue; } #principal { color: green; }

⚙️ Propriedades

Definem o que será alterado.

color, font-size, background-color, margin

🎨 Valores

Definem como será aplicado.

color: blue; font-size: 20px;

💻 Exemplo

h1 { color: #22c55e; }

🧠 Conclusão

O CSS é essencial para criar sites modernos, organizados e visualmente agradáveis.
