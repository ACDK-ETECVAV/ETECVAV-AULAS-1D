Sobre Nós

Somos estudantes da Etec Vasco Antônio Venchiarutti, cursando o curso técnico em Informática para Internet. Este site foi desenvolvido como parte de um projeto acadêmico para a disciplina de Desenvolvimento Web.

Nosso objetivo é apresentar informações práticas sobre o framework Bootstrap, abordando sua importância, conceitos de responsividade, aplicação de classes CSS prontas e componentes visuais para o desenvolvimento ágil.

Objetivo do Site

O objetivo deste site é fornecer informações sobre a empresa fictícia ACKP | INF., destacando sua história, missão, equipe e serviços oferecidos. Além disso, o site serve como um exemplo prático de aplicação do framework Bootstrap, demonstrando conceitos de design responsivo e utilização de componentes visuais.
