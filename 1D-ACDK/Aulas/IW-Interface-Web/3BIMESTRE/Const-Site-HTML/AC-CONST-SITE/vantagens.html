Vantagens e cuidados

A computação em nuvem trouxe muitas facilidades, mas como toda tecnologia, também exige alguns cuidados. Veja abaixo os principais pontos.

✔ Vantagens

  • Economia: não precisa comprar servidores caros
  • Acesso de qualquer lugar com internet
  • Backup automático dos arquivos
  • Fácil de aumentar ou diminuir o uso conforme a necessidade
  • Atualizações feitas pela própria empresa do serviço

✖ Cuidados

  • Depende de conexão com a internet
  • É preciso usar senhas fortes para proteger os dados
  • Os dados ficam guardados em empresas de terceiros
  • Custos podem crescer se o uso não for controlado

Curiosidade

Estima-se que a maior parte das empresas do mundo já use algum tipo de serviço em nuvem. Até jogos e inteligência artificial funcionam hoje graças a grandes centros de dados na nuvem.
