Sobre o site

Este site foi criado como trabalho escolar do Grupo A, com o tema Computação em Nuvem. O objetivo é explicar de forma simples o que é a nuvem, como ela funciona e por que ela é tão usada hoje em dia.

Escolhemos usar uma linguagem fácil de entender, com exemplos do dia a dia, para que qualquer pessoa consiga aprender sobre o assunto, mesmo sem conhecer muito de tecnologia.

Um pouco de história

A ideia de compartilhar recursos de computação existe desde os anos 1960, mas o termo "computação em nuvem" ficou popular a partir de 2006, quando grandes empresas começaram a oferecer serviços de nuvem para o público. Hoje, empresas como Amazon (AWS), Microsoft (Azure) e Google (Google Cloud) são as maiores fornecedoras desse tipo de serviço no mundo.

Como o site foi feito

O site foi desenvolvido usando HTML e o framework Bootstrap, que ajuda a deixar as páginas organizadas e adaptadas para celular e computador.
