Objetivo do Projeto

Este site foi desenvolvido com o objetivo de apresentar os conceitos básicos de CSS, demonstrando como a linguagem é utilizada para estilizar páginas web.

O projeto também mostra a utilização do conceito Mobile First, permitindo que a página funcione corretamente em celulares, tablets e computadores.
