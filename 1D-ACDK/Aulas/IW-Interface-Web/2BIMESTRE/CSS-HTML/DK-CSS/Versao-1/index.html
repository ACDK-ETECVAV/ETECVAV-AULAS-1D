INTRODUÇÃO AO CSS

Aprendendo estilização web

O que é CSS?

CSS é uma linguagem utilizada para personalizar páginas HTML. Com ele, podemos alterar cores, tamanhos, fontes e posicionamento dos elementos.

Ele ajuda a deixar os sites mais modernos, organizados e agradáveis visualmente.

Como funciona?

O CSS funciona aplicando estilos aos elementos do HTML através de seletores. 

h1 {
    color: blue;
}

Nesse exemplo, todos os títulos h1 ficarão azuis.

Principais Propriedades

As propriedades definem quais mudanças serão aplicadas aos elementos. 

color
font-family
margin
padding

Exemplos de Valores

Os valores mostram como a propriedade será utilizada. 

color: green;
font-size: 18px;

Sites Responsivos

Utilizando Mobile First, o site é desenvolvido primeiro para celulares e depois adaptado para telas maiores utilizando Media Queries.

Finalização

O CSS é fundamental para o desenvolvimento web moderno, permitindo criar páginas bonitas e responsivas.
