## Instruções

### Objetivo

O objetivo desta atividade é compreender como um problema pode ser resolvido utilizando os conceitos do **Pensamento Computacional**.

Antes de escrever um algoritmo, é necessário analisar o problema, identificar suas características e planejar uma solução.

---

## O que é Pensamento Computacional?

O Pensamento Computacional é uma forma organizada de analisar problemas e desenvolver soluções que possam ser executadas por pessoas ou computadores.

Ele é baseado em quatro pilares fundamentais:

### 1. Decomposição

Consiste em dividir um problema grande em problemas menores, tornando sua resolução mais simples.

**Exemplo:**

Em um sistema de biblioteca, podemos separar o problema em:

- Cadastro de alunos;
- Cadastro de livros;
- Empréstimo;
- Devolução;
- Consulta de livros.

### 2. Reconhecimento de Padrões

Após dividir o problema, devemos observar quais tarefas ou comportamentos se repetem.

**Exemplo:**

Sempre que um produto é vendido:

- o cliente é identificado;
- o produto é escolhido;
- o valor é calculado;
- o pagamento é realizado.

Esses passos se repetem diversas vezes e podem ser transformados em um algoritmo.

### 3. Abstração

Nem todas as informações são importantes para resolver um problema.

A abstração consiste em identificar apenas os dados realmente necessários.

**Exemplo:**

Em um sistema de controle de alunos, geralmente interessam:

- nome;
- matrícula;
- notas;
- frequência.

Informações como cor da mochila, marca do tênis ou cor do cabelo normalmente não influenciam a solução e podem ser desconsideradas.

### 4. Algoritmo

Depois de compreender o problema, identificar os padrões e selecionar apenas as informações importantes, é possível construir um algoritmo.

O algoritmo representa uma sequência lógica e organizada de instruções capaz de resolver o problema proposto.

# Desenvolvimento da Atividade

Os alunos deverão formar grupos de **3 ou 4 alunos**.

Cada grupo escolherá **um dos temas abaixo**.

Para o tema escolhido, o grupo deverá apresentar:

## Etapa 1 – Decomposição

Descreva o problema e responda:

- Qual é o objetivo do sistema?
- Quais informações serão necessárias?
- Quais tarefas o sistema deverá realizar?

## Etapa 2 – Reconhecimento de Padrões

Identifique quais processos se repetem durante a execução do sistema.

## Etapa 3 – Abstração

Liste:

### Informações importantes

Liste as informações necessárias para resolver o problema.

### Informações que podem ser descartadas

Liste as informações que não são necessárias.

**Justifique sua resposta.**

## Etapa 4 – Algoritmo

Desenvolva um algoritmo em **Visualg ou Portugol Studio** que resolva o problema proposto.

O algoritmo deverá utilizar os conhecimentos estudados durante as aulas.

---

# Temas

## 1. Organizador de Estudos

Desenvolver um sistema que auxilie um estudante na organização de sua rotina de estudos.

O sistema poderá controlar:

- disciplinas;
- tempo de estudo;
- metas diárias;
- desempenho.

## 2. Controle de Cantina

Desenvolver um sistema para registrar compras realizadas na cantina da escola.

O sistema poderá:

- calcular valores;
- calcular descontos;
- calcular troco;
- calcular o total das vendas.

## 3. Jogo RPG

Criar um jogo simples em que o jogador controla um personagem.

O sistema poderá gerenciar:

- atributos do personagem;
- ataques;
- defesa;
- vida;
- evolução.

## 4. Academia

Desenvolver um sistema para auxiliar no acompanhamento de treinos.

O sistema poderá:

- calcular IMC;
- registrar metas;
- acompanhar a evolução do aluno.

## 5. Controle de Cinema

Criar um sistema para venda de ingressos.

O sistema poderá controlar:

- sessões;
- lugares disponíveis;
- valores;
- classificação indicativa.

## 6. Quiz

Desenvolver um jogo de perguntas e respostas.

O sistema deverá:

- registrar as respostas do jogador;
- calcular sua pontuação.

## 7. Pet Shop

Criar um sistema para atendimento de animais.

O sistema poderá registrar:

- dados do pet;
- serviços solicitados;
- valor do atendimento.

## 8. Controle de Viagem

Desenvolver um sistema que auxilie no planejamento de uma viagem.

O sistema poderá calcular:

- distância;
- consumo de combustível;
- custos;
- tempo estimado.

## 9. Calculadora Financeira

Criar um sistema para controle financeiro pessoal.

O sistema poderá calcular:

- receitas;
- despesas;
- economia;
- metas financeiras.

## 10. Agenda Escolar

Desenvolver um sistema para organizar atividades escolares.

O sistema poderá registrar:

- tarefas;
- disciplinas;
- datas de entrega;
- prioridades.

- Documento contendo a identificação dos quatro pilares do Pensamento Computacional;
- Descrição do problema escolhido;
- Resolução das quatro etapas propostas;
- Algoritmo desenvolvido em Visualg ou Portugol Studio.
