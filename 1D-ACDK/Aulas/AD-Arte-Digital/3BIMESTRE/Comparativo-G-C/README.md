# 🖼️ Pesquisa: Comparativo entre GIMP e Canva

## 📚 Objetivo

Compreender as diferenças entre as ferramentas de edição de imagens **GIMP** e **Canva**, analisando suas características, funcionalidades, finalidades e público-alvo por meio de um **texto dissertativo comparativo**.

---

## 📝 O que deve ser feito

Desenvolva um **texto dissertativo** comparando o **GIMP** e o **Canva**, abordando obrigatoriamente os seguintes tópicos:

### 1. O que são

Apresente uma breve descrição de cada ferramenta, incluindo:

- Definição do **GIMP**;
- Definição do **Canva**;
- Desenvolvedor(es);
- Licença de uso;
- Plataformas compatíveis (Windows, Linux, Web, etc.).

### 2. Principais diferenças

Compare os softwares considerando:

- Tipo de licença (gratuito × gratuito/pago);
- Público-alvo;
- Foco principal (edição profissional × design rápido);
- Formatos de arquivos suportados.

### 3. Quando utilizar cada ferramenta

Explique em quais situações:

- O **GIMP** é a melhor escolha;
- O **Canva** se destaca como a opção mais adequada.
