# 📘 Elaboração de Infográfico - Formas Normais

## 📅 Data de conclusão
**11 de junho de 2026 às 23:59**

---

# 🎯 Objetivo

Levar o estudante a compreender, organizar e comunicar de forma visual os conceitos fundamentais da normalização de dados, com foco na:

- Primeira Forma Normal (1FN)
- Segunda Forma Normal (2FN)
- Terceira Forma Normal (3FN)

---

# 📝 Descrição da atividade

Os alunos deverão trabalhar **individualmente ou em dupla** para produzir um **infográfico digital** que explique de maneira clara e objetiva as três formas normais.

O infográfico deve ser **autoexplicativo**, ou seja, qualquer pessoa com conhecimento básico na área deve conseguir entender o conteúdo sem necessidade de explicações adicionais.

---

# 📌 Etapas

## 1️⃣ Desenvolver o infográfico contendo:

- Definição de cada forma normal:
  - Primeira Forma Normal (1FN)
  - Segunda Forma Normal (2FN)
  - Terceira Forma Normal (3FN)

- Exemplos práticos com:
  - Tabelas antes da normalização
  - Tabelas depois da normalização

- Ilustrações ou esquemas que facilitem o entendimento

- Comparação entre as três formas normais

---

## 2️⃣ Organização visual

Organizar o conteúdo de forma:

- Visualmente atrativa
- Clara
- Objetiva
- Sintética

---

# 🛠️ Ferramentas sugeridas

Pode-se utilizar ferramentas digitais como:

- Canva
- PowerPoint
- Outras plataformas de design gráfico

---

# 📤 Formato de entrega

- Arquivo em **PDF**
- Enviado pelo **Teams**
