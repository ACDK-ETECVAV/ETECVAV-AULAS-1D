# 🗄️ Atividade — Funções de Data e Hora em SQL

## 📌 Sobre a Atividade

Nesta atividade, serão utilizadas as estruturas do banco de dados **`bd_infonet`** e da tabela **`funcionario`**, criadas anteriormente em aula.

O objetivo é realizar alterações na tabela para adicionar informações relacionadas às datas dos funcionários e, em seguida, utilizar **funções de data e hora em SQL** para realizar consultas e análises.

---

## 🎯 Objetivos

- Alterar uma tabela existente utilizando `ALTER TABLE`.
- Adicionar campos de data ao cadastro dos funcionários.
- Trabalhar com **datas de nascimento** e **datas de admissão**.
- Utilizar funções de data e hora em consultas SQL.
- Filtrar registros utilizando períodos e anos.
- Separar dia, mês e ano de uma data.
- Trabalhar com nomes de meses.
- Calcular idade.
- Realizar consultas utilizando condições de data.
- Utilizar ordenação e remoção de resultados duplicados.
